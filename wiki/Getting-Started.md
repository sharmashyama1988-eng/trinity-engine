# 🚀 Getting Started with Trinity Engine

## Prerequisites
- **Windows 10/11** (64-bit recommended)
- **Python 3.10+**
- **Administrator Privileges** (Required for kernel tweaks)

## Installation Steps
1. **Clone the Project:**
   ```bash
   git clone https://github.com/sharmashyama1988-eng/trinity-engine.git
   cd trinity-engine
   ```
2. **Environment Setup:**
   Create a virtual environment and install dependencies:
   ```bash
   python -m venv .venv
   source .venv/Scripts/activate
   pip install -r requirements.txt
   ```
3. **Launch:**
   Run the main entry point:
   ```bash
   python main.py
   ```

## First Steps inside the App
- **Check Status:** Ensure the 'ROOT' badge is visible (indicates Admin rights).
- **Engage Protocol:** Click the central orb to run the first optimization cycle.
- **Set Settings:** Go to the 'Core' tab to enable Auto-Boost on startup.
